- **Дата архивации:** 2025-11-16
- **Описание:** Базовая схема приложения (таблицы `users`, `contacts`, расширения `pgcrypto`, `citext`)

- **Причина:** Применена ко всем существующим базам данных

## ⚠️ ВАЖНО

**Эти миграции архивированы ДО создания golden schema.**

Это означает:
- ✅ Существующие базы данных уже имеют эти изменения
- ❌ Новые базы данных (Pro tenants) НЕ получат эти миграции автоматически
- ⚠️ **Необходимо создать `bundle/app_schema_full.sql`** перед онбордингом новых Pro tenants

## Следующие шаги

1. Создать `tools/generate_bundle.go` для генерации golden schema
2. Включить все архивированные миграции в bundle
3. Обновить процесс онбординга для использования bundle вместо миграций
